Import your playtest PDFs

{{#if missing}}

Install Crows PDF Importer (Unofficial) on your Foundry host, then enable it in this world under Settings → Manage Modules.

Install the module from its release ZIP in Data/modules/fvtt-crows-pdf-importer and restart Foundry. Use it with Crows v0.2.1.

{{/if}} {{#if disabled}}

Crows PDF Importer (Unofficial) is installed. Enable it under Settings → Manage Modules and let the world reload.

{{/if}} {{#if unavailable}}

Crows PDF Importer (Unofficial) is enabled, but its importer is unavailable. Reload the world. If this persists, check that the system and module versions are compatible and check the console for startup errors.

{{/if}}

Then reopen Import Playtest Content, select your extracted packet folder, and review the content before saving it.
