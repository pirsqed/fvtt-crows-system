Crows for Foundry

Greetings, Crows and Refs!

Let's bring your playtest packet into Foundry so you can start playing Crows.

The short version

Install and enable Crows PDF Importer module → select your packet folder → extract → review and import.

The Ref (GM) imports once for the world. Players use the imported content to create their Crows.

You'll need your own MCDM playtest PDFs. The module reads them in your browser. Equipment, traits, creatures, backgrounds, and NPC connection benefits come from your packet. Keep the books handy for the rules.

1. Enable the PDF importer

Install Crows PDF Importer on the Foundry host, then enable it in your world under Settings → Manage Modules. Let the world reload.

From Foundry's Setup screen, open Add-on Modules → Install Module. Paste this link into Manifest URL and click Install:

https://github.com/pirsqed/fvtt-crows-pdf-importer/releases/latest/download/module.json

The link follows the latest published stable module release. Pair importer v0.1.1 with Crows v0.2.2 or later. For manual installation, extract the release ZIP into Data/modules/fvtt-crows-pdf-importer and restart Foundry.

2. Select your packet

Download and extract the playtest ZIP on the computer where you're using the browser. Keep the original filenames and subfolders, with one copy each of the Characters book, Ref book, core Inventory Cards, Profession cards, and POI/Dungeon cards.

Open Settings → Configure Settings → Crows → Import Playtest Content, or use the button below. Choose Packet folder and select the extracted folder. Subfolders are included. You can also choose Individual PDFs to select the books individually.

For a hosted game, select the PDFs from your own computer. Extraction runs in your browser; the reviewed content is saved to the Foundry world.

3. Extract and choose entries

Check the detected book assignments and click Extract selected PDFs. Assign renamed files manually and skip duplicate copies or unrelated books. Include the core inventory PDF with the Characters book so starting spellbooks can resolve. Extraction saves nothing to your world.

When extraction finishes, click Choose entries & review →. All entries start selected. Choose individual entries with their checkboxes, or use search and the category filter to narrow the list.

Just want a few items?

Clear the search, choose All categories, then click Deselect visible. Search for what you want and tick its checkbox. Select visible and Deselect visible affect only the displayed entries; hidden selections remain selected. Check the total selection count before continuing.

Repeated copies are combined. Lore Books with a named expertise are separate entries, such as Lore Book (Nature). If other definitions conflict, choose the one to keep or skip that entry.

4. Choose your import options

Update character-creation content publishes backgrounds, NPC connections and starting kits for Create a Crow. Leave it on for initial setup. Required equipment, traits and pets must be selected or already available in the world compendiums. The review tells you if something is missing.

For a standalone item or creature import, turn this option off. Previously published character-creation content stays available. The option is unavailable if complete background/connection data wasn't extracted.

Force overwrite existing entries is off by default. Enable it to replace imported fields on edited or untracked entries, including a creature's embedded Items such as attacks and traits. Existing artwork, parent document IDs, folders and ownership stay intact; replaced embedded Items get new IDs. Ambiguous duplicates remain preserved.

5. Review and import

As the active GM, click Check world and review changes. Unlock any locked target compendiums first. Each selected entry has a result:

  • create: adds a new compendium entry.
  • update: changes the existing entry. Check force-overwrite updates carefully if you edited that content.
  • unchanged: the content is already current.
  • preserve: keeps the existing entry; the Details column explains why.

Click Import selected entries to save. Changing your selection or options requires a fresh review. The importer also asks for another check if the world changed after review.

Your equipment, dungeon loot, traits and creatures appear in Compendium Packs. With character-creation publishing enabled, backgrounds and NPC connections become available through Settings → Configure Settings → Crows → Create a Crow.

What should a full import contain?

The current packet produces 134 equipment entries, 40 dungeon-loot entries, 276 traits and 71 creatures: 521 entries across four compendiums. Character creation also receives 36 backgrounds and 10 NPC connection choices.

Some fresh-import icons remain generic. Importing the separate creature artwork is still pending.

Re-importing or stopping an import

Default imports preserve local edits, older untracked entries and changed creature inventories. They update unedited tracked Items and retain custom artwork. Compendium imports don't replace copies already placed on character sheets or scenes.

Stop after current entry keeps completed changes. Errors can also leave partial changes, especially during forced creature-inventory replacement. Read the result and review again before retrying. Character-creation content is published only after a successful import.

After editing compendiums, repeat review/import with Update character-creation content enabled to refresh what the creator uses.

Something didn't work?
  • Module missing or disabled: follow the message shown by Open PDF Importer, then reload the world.
  • Folder selection unavailable: use Individual PDFs and select the five books.
  • Missing or duplicate books: extract the ZIP first, check the selected folder, and resolve duplicate assignments before extraction.
  • Background spellbooks unresolved: include the core inventory PDF with the Characters book.
  • Missing creator reference: select the named equipment, trait or pet, or turn off character-creation publishing for a standalone import.
  • Target pack locked: unlock it in Compendium Packs, then check the world again.
  • World changed after review: check the world again before importing.
  • Extraction error: keep the error message and book/page details when reporting the issue. Future PDF layouts may require an importer update.

Ready for the rest?

Foundry helps with rolls, slots, and resource tracking. You and the Ref still handle most trait effects, spell effects, ammunition spending, and downtime. A button does its named action; it doesn't resolve every rule around it. The play guide explains what's automatic and what's manual.

The full docs on GitHub cover character creation, item management, permissions, villages, and more. Please give it a try and let me know how it goes. ^_^
