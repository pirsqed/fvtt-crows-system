Legacy generated-file import

Build the files from your own PDFs, then import them below. Re-imports preserve local edits and never delete entries.

How to build the content

For the PDF-folder workflow, open the setup guide. The instructions below are for the legacy Python builder.

  1. Extract your playtest ZIP into the included pdfs/ folder inside the system folder. Its ADD_PDFS_HERE.txt note has the short instructions.
  2. Windows: open build_playtest_content.cmd.
    Linux: run sh build_playtest_content.sh --setup --interactive from the system folder.
  3. Click Re-check files, then import. See LEGACY-IMPORT.md in the system folder for the legacy builder instructions.

Only unedited, tracked entries are updated. Older imports, local edits, and changed actors are preserved for review.
